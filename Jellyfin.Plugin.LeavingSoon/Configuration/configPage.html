Leaving Soon

Surfaces scheduled-deletion media as symlink-backed libraries in Jellyfin. The plugin polls one or more provider apps and manages the symlinks, the virtual folders, and the library refreshes itself.

Libraries

Host directory for symlinks. The plugin creates movies and tv subdirectories under it.
Delete empty libraries instead of showing them in the sidebar.

Sync

How often to poll the providers.
Consecutive provider failures tolerated before an empty result is treated as authoritative (so a temporarily-down provider doesn't wipe the libraries).

Providers

Each provider is polled for leaving-soon items. maintainerr and oxicleanarr are supported.
