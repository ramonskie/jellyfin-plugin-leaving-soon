Leaving Soon

Surfaces scheduled-deletion media as symlink-backed libraries in Jellyfin.

The plugin polls one or more provider apps for "leaving soon" media and manages the symlinks, the virtual folders, and the library refreshes itself.

Configuration

Edit config.xml in this plugin's config directory and restart Jellyfin. The web UI for this plugin is read-only.

Key settings:

  • BasePath - host directory for symlinks (movies and tv subdirectories)
  • MoviesLibraryName / TvLibraryName - Jellyfin library names
  • HideWhenEmpty - delete empty libraries instead of showing them
  • SyncIntervalMinutes - poll interval
  • Providers - list of maintainerr and/or oxicleanarr sources

How it works

  1. On the configured interval the plugin polls every enabled provider.
  2. Each provider returns the normalized leaving-soon contract (mediaServerId, type, deletionDate).
  3. The plugin resolves each item's on-disk path from Jellyfin's own metadata.
  4. It reconciles the symlinks, virtual folders, and refreshes the libraries.
